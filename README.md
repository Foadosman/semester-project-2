# Semester project 2

BidWorld is a auction web application built for Semester Project 2. Users can browse auction listings, register with a `@stud.noroff.no` email, log in, create listings, edit their profile, and place bids using virtual credits.

## Live Site

https://bidworld.netlify.app/

## GitHub Repository

https://github.com/Foadosman/semester-project-2

## Description

This project uses the Noroff Auction House API. Visitors can browse and search listings, while registered users can access extra features such as creating listings, editing their profile, viewing credits, and placing bids.

## Features

- Browse listings without logging in
- Search and sort listings
- View single listing pages
- View bid history
- Register with a `@stud.noroff.no` email
- Login and logout
- View credits in the navbar
- Create listings
- Edit and delete own listings
- Place bids on other users' listings
- Edit profile bio, avatar and banner
- Responsive design for desktop and mobile
